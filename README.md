# SKYREACH

Hang-glide **Halcyon Reach**, an original waterfront city. Walk the streets and rooftops, climb the landmarks, then open the wing and ride thermals over the bay.

No accounts, no API keys. Progress stays in this browser.

## Play

```bash
npm install
npm run dev
```

- **WASD** move, **Shift** sprint, **Space** jump
- **Mouse** looks around. In the air it steers the wing
- **G** opens or stows the hang glider
- **W / S** dive and climb, **A / D** bank, **Space** flares for landing
- **C** atlas, **M** map, **N** time of day, **R** clears a ring run, **Esc** pauses

Sprint off a roof or climb somewhere high before the wing will catch. From the Crown, point the nose down to build speed, and circle the amber columns to climb back up.

Twelve landmarks, a trail of sunmotes, and six ring runs are saved locally.

## Build

```bash
npm run build

```
